04 — Reglas

Buenas prácticas

Para que el sistema se mantenga coherente en cualquier formato.

Sí

  • Plus Jakarta Sans 700 en MAYÚSCULAS para los titulares principales.
  • DM Mono para cifras, fechas, labels y el tagline — siempre en uppercase con tracking amplio.
  • Un solo uso de Ember (#FF5C39) por pieza, en el elemento más importante.
  • Fondo primario #0A0612 como base; #1A1128 para superficies secundarias.

No

  • No introducir otras fuentes (Inter, Montserrat, Satoshi, etc.).
  • No usar DM Mono en párrafos largos ni en minúsculas continuas.
  • No usar Ember dos veces en la misma pieza — pierde su fuerza.
  • Sin gradientes, glows, drop shadows ni efectos decorativos.
05 — Implementación

Pegar en cualquier proyecto

Carga las fuentes e importa v2-tokens.css — o usa estas variables directamente.

/* 1. Google Fonts */
<link href="https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:ital,wght@0,300;0,400;0,500;0,700;1,400;1,700&family=DM+Mono:wght@400;500&display=swap" rel="stylesheet">

/* 2. Tokens tipográficos */
--sans: 'Plus Jakarta Sans', system-ui, sans-serif;
--mono: 'DM Mono', ui-monospace, monospace;

/* 3. Paleta v2.0 */
--bg: #0A0612; /* Deep Ink — fondo principal */
--bg-2: #1A1128; /* Surface — cards, hover */
--border: #2A1F3D; /* Bordes y separadores */
--t1: #FAF8FC; /* Texto primario */
--t2: #9A8CB0; /* Texto secundario */
--t3: #8B7C9E; /* Texto de apoyo */
--ember: #FF5C39; /* Acento único — Electric Ember */
